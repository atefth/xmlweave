# Changelog

## 0.1.0 — release candidate

- Correct schema version/annotation metadata handling and source diagnostic identity; abort stalled sources without poisoning unrelated hint requests or admission slots.
- Verify 100 mixed validation lifecycles, clean pinned native rebuilds and expanded standards/Java compatibility cases before first publication.
- Add a newcomer guide, multi-file validation example and npm version badge.
- Replace the default XSD engine with packaged Xerces-C++ WASM after a confirmed libxml2 base64 conformance defect; retain the legacy worker as an explicit optional companion.
- Add original-source diagnostics, strict byte decoding, DOM/chunk sources, independent sessions and immutable processing ceilings.
- Add isolated native schema graphs, real incremental SAX/PSVI output, worker deadlines, actual type derivation metadata and an explicit OpenJDK-derived Java provider.
- Add bounded push/pull event adapters, namespace-prefix output settings, event-point locator correlation, augmented results, exact handler forwarding and shipped provider factories.
- Add grammar-scoped anonymous type identity and idle derivation queries; preserve processing instructions and namespace-correct default attributes in collected output.
- Add document-wide approved instance hints, canonical pinned catalogues, bounded compiled-grammar caches and operation deadlines.
- Add exact isolated diagnostic-handler handshakes with conditional browser cross-origin isolation; distinguish instrumented warning transport tests from observed native warning conditions.
- Add selected unchanged W3C/NIST fixtures, Java differential checks, pinned native rebuild inputs/assets/licenses and packed Node/browser coverage. The initial delivery passed its complete CI matrix.

- Add optional typed XPath queries, incremental pull-driven streaming, disposable asynchronous XSD validation and constrained XSLT transformations.
- Add isolated companion consumer fixtures, all-entry-point declarations, browser/WASM regression checks and explicit external-resource policies.
- Add engine evaluations, retained optional dependency notices and documented scope decisions for signatures, SOAP and mapping.

- Add synchronous XML parsing, namespace-aware document creation and mutation, and well-formed serialization.
- Add stable facade error codes, mandatory DTD rejection and bounded input, output, depth and node policies.
- Add shared ESM/CJS runtime identity, declarations without DOM/Node ambient types, isolated packed-consumer fixtures and real browser verification.
- Record engine evaluation, retain dependency notices and apply the owner-approved MIT project license. Registry publication is explicitly authorized for the first public release.
